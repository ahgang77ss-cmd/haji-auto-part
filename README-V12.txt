نسخه V12 — Price Tracker

امکانات:
- نمایش تعداد قیمت‌های با تطبیق معتبر
- نمایش تعداد قیمت‌های تغییرکرده
- نمایش افزایش و کاهش قیمت با درصد روی کارت
- نگهداری price-history.json برای تاریخچه تغییرات
- price-updater.js برای اجرای بروزرسانی روی سرور Node.js
- قیمت حدسی وارد سایت نمی‌شود؛ فقط تطبیق معتبر جایگزین می‌شود.

نکته مهم: برای بروزرسانی واقعی تمام ۲۲۲۴ قطعه، این نسخه باید روی محیطی که دسترسی اینترنت/منبع قیمت و اجرای زمان‌بندی‌شده دارد اجرا شود. این بسته عمداً قیمت جعلی یا تخمینی تولید نمی‌کند.
