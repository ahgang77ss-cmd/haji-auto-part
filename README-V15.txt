نسخه V15 — داشبورد حرفه‌ای سفارش‌ها

بر پایه V14 ساخته شده و فایل‌های فروشگاه، موتور قیمت و سیستم سفارش حفظ شده‌اند.

امکانات جدید پنل مدیریت:
- داشبورد آماری: کل سفارش‌ها، جدید، آماده‌سازی، تکمیل‌شده و ارزش کل سفارش‌ها
- نمودار وضعیت سفارش‌ها
- پرفروش‌ترین قطعات بر اساس تعداد
- جستجو با کد سفارش، نام و شماره تماس
- فیلتر وضعیت
- فیلتر بازه تاریخ
- مشاهده جزئیات کامل هر سفارش در پنجره جداگانه
- نمایش اقلام، تعداد، قیمت واحد، جمع هر قلم، مشتری، آدرس، روش تحویل، یادداشت و زمان‌ها
- تغییر وضعیت سفارش
- حذف سفارش
- طراحی RTL و ریسپانسیو برای موبایل و دسکتاپ

اجرای محلی:
npm install
npm start
سپس: http://localhost:3000

ورود پیش‌فرض توسعه:
username: admin
password: CHANGE-ME-NOW

در سرور واقعی حتماً ADMIN_USER و ADMIN_PASSWORD را با متغیر محیطی امن تغییر دهید و سایت را پشت HTTPS و reverse proxy اجرا کنید.
