V11 price update

This build applies a verified snapshot of selected market prices found on 2026-09-09 / 1405-06-18 from public seller/catalog pages. It does NOT pretend that every one of the 2224 products has a verified live price. Unmatched products retain their existing displayed price until a reliable match is found.

Sources:
- https://yadaki-sena.ir/
- https://persiayadak.com/
- https://parsinyadak.com/
- https://kamayadak.com/showcategories?catName=saipa

For true automatic 6-hour updates, a server/worker with permitted source access is required; a static HTML file cannot autonomously run in the background when nobody visits it.
