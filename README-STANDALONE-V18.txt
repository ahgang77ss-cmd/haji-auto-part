لوازم یدکی برادران حاجی — نسخه Standalone V18

این نسخه برای حذف کامل مشکل npm/Express ساخته شده است.

فناوری:
- Node.js built-in HTTP server
- SQLite از node:sqlite خود Node.js
- بدون Express
- بدون node_modules
- بدون npm install
- بدون نیاز به دسترسی به registry.npmjs.org برای اجرای سایت

اجرا در ویندوز:
1) ZIP را استخراج کن.
2) وارد پوشه site شو.
3) روی start-windows.bat دوبار کلیک کن.
4) پنجره مشکی را نبند.
5) Chrome → http://localhost:3000

پنل مدیریت:
http://localhost:3000/admin

سلامت سرور:
http://localhost:3000/api/health

ورود پیش‌فرض:
نام کاربری: admin
رمز عبور: CHANGE-ME-NOW

قابلیت‌های حفظ‌شده:
- ثبت سفارش
- صفحه موفقیت سفارش
- پنل مدیریت
- جستجو و فیلتر سفارش‌ها
- تغییر وضعیت سفارش
- اعلان‌ها
- گزارش فروش
- موجودی و رزرو موجودی
- وضعیت پرداخت
- SQLite و مهاجرت سفارش‌های قدیمی
- کاتالوگ و قیمت‌ها

تست شده:
- node --check server.js
- اجرای سرور روی localhost:3000
- /api/health
- صفحه اصلی
- صفحه admin
- ورود مدیر
- موجودی
- ثبت سفارش آزمایشی
- رزرو موجودی
- تکمیل سفارش و کسر موجودی

نکته:
اولین اجرای سرور، دیتابیس SQLite را داخل پوشه data می‌سازد و در صورت وجود orders.json قدیمی، سفارش‌ها را مهاجرت می‌دهد.
