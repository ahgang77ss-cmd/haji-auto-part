سیستم سفارش و پنل مدیریت — لوازم یدکی برادران حاجی

اجزای جدید:
- server.js: بک‌اند Node.js + Express
- data/orders.json: محل ذخیره سفارش‌ها (JSON)
- admin.html: پنل مدیریت سفارش‌ها
- order-success.html: صفحه موفقیت ثبت سفارش
- index.html: ارسال واقعی فرم سفارش به /api/orders

راه‌اندازی روی هاست/سرور:
1) Node.js 18 یا بالاتر نصب باشد.
2) داخل همین پوشه اجرا کنید:
   npm install
3) برای امنیت، متغیرهای محیطی تنظیم کنید:
   ADMIN_USER=admin
   ADMIN_PASSWORD=یک-رمز-قوی
   PORT=3000
4) اجرا:
   npm start
5) صفحه فروشگاه: /
6) پنل: /admin

نکته امنیتی:
- رمز پیش‌فرض کدشده نیست و باید حتماً قبل از انتشار روی اینترنت تغییر کند.
- بهتر است سرور پشت HTTPS باشد.
- فعلاً پرداخت آنلاین در این نسخه وجود ندارد؛ فقط ثبت و مدیریت سفارش انجام می‌شود.
